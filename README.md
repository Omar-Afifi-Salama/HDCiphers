# 🔒 HDCiphers (Hyper Dynamic Ciphers)

`hdciphers` is a modern, fluent Python cryptography library designed for exploring classical and advanced substitution ciphers across universal language scripts. 

Unlike traditional libraries restricted to the 26 letters of the English alphabet, `hdciphers` features a robust, algebraic Unicode **Charset Engine** and a state-tracking **Text Stack** that calculates cryptographic telemetry (like Shannon Entropy) in real-time.

---

## ✨ Key Features

* 🚀 **Fluent Chaining API:** Chain multi-layered encryptions cleanly in a single line of code.
* 🧮 **Charset Algebra:** Combine or subtract alphabets natively using standard math operators (`+`, `-`).
* 🌍 **Universal Script Support:** Pre-configured sets for English, Arabic (with native numbers/punctuation), Greek, and programmatic **Exotic Unicode Pools**.
* 📉 **Cryptographic Telemetry:** Built-in calculation of **Shannon Entropy** to instantly measure ciphertext randomness.
* 📜 **Immutable Transaction Stack:** Automated tracking history with an instant `.unwind()` rollback feature.
